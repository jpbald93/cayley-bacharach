# The Cayley–Bacharach theorem for plane cubics in Lean 4

A Lean 4 + Mathlib formalisation of the **Cayley–Bacharach theorem** for plane cubics: two cubics
meeting in nine points, and a third cubic through eight of them. Covered: the exact
general-position criterion for eight points, the theorem over arbitrary fields (finite fields
included), its classical "exactly nine common zeros" form with sharp field-size thresholds, and
Pascal's and Pappus's theorems derived from it.

> Let `K` be a field and `P₀,…,P₈` nine pairwise non-proportional points of `K³`. Let `F, G` be
> linearly independent cubics vanishing at all nine. Suppose no five of `P₀,…,P₇` are collinear and
> `P₀,…,P₇` do not all lie on a conic. Then every cubic `H` vanishing at `P₀,…,P₇` also vanishes at `P₈`.

**Status:** all statements proved, with no `sorry`. `gate.sh` checks 73 named declarations.

Points are nonzero vectors `Fin 3 → K` (read up to scaling), cubics are coefficient vectors
`Fin 10 → K` (`PlaneCubic K`), and conics are coefficient vectors `Fin 6 → K`.

## Main statements

| Lean name | File | Statement |
|---|---|---|
| `PlaneCubic.finrank_ker_evalMap_eq_two` | `General.lean` | eight points with no five collinear and not all on a conic impose independent conditions on cubics (the cubics through them form a 2-dimensional space) |
| `PlaneCubic.finrank_ker_ge_of_line`, `finrank_ker_ge_of_conic` | `Criterion.lean` | converse: five collinear points, or eight on a conic, leave a space of dimension ≥ 3 |
| `PlaneCubic.cayley_bacharach` | `Theorem.lean` | Cayley–Bacharach, general-position form (infinite fields) |
| `PlaneCubic.cayley_bacharach_any` | `FiniteField.lean` | the same over **every** field, finite fields included |
| `PlaneCubic.cayley_bacharach_of_no_common_factor` | `Factor.lean` | form with the hypothesis "`F`, `G` share no line and no conic" |
| `PlaneCubic.cayley_bacharach_classical` | `Classical.lean` | textbook form: the common zeros of `F`, `G` are exactly the nine points (any infinite field; no algebraic closure needed) |
| `PlaneCubic.cayley_bacharach_classical_card8` | `ClassicalSmall.lean` | the textbook form over finite fields with at least 8 elements |
| `PlaneCubic.line_lemma_false_zmod_two` | `Line.lean` | the key line lemma fails over `𝔽₂` |
| `PlaneCubic.pascal_clean` | `PascalClean.lean` | Pascal's theorem from Cayley–Bacharach: six distinct points on a conic that is not a line pair |
| `PlaneCubic.pappus_clean` | `PappusClean.lean` | Pappus's theorem from Cayley–Bacharach |
| `PlaneCubic.det_gram_eq_zero_iff` | `PappusClean.lean` | a conic is a line pair iff its symmetric matrix is singular (`2 ≠ 0`, algebraically closed) |

The textbook form is **false** over `𝔽₄`, `𝔽₅` and `𝔽₇` (explicit counterexamples in
`code/counterexamples.py`), and a brute-force search indicates it holds over `𝔽₃`; that case is
not formalised. There is no field with 10 elements, so `|K| ≥ 8` covers every field above `𝔽₇`.

A companion development, [`pascal-hexagon`](https://github.com/jpbald93/pascal-hexagon), proves a
more general Pascal theorem by a different method.

## Verification

`./gate.sh` builds the library and generates its own `#print axioms` queries for the 73 named
declarations (every Lean name cited in the accompanying paper). The queries are generated by the
gate itself, not read from a file in the repository.

The gate fails if any of the following is true:
- a source file contains `sorry`, `admit`, `native_decide`, `axiom`, `#eval`, `run_cmd`, `set_option`, `macro`/`elab`/`syntax`/`notation`, or `import Lean`;
- the build fails;
- a named declaration is missing, or has an extra report;
- a named declaration depends on anything other than `propext`, `Classical.choice` and `Quot.sound`.

Output: `PASS (73 theorems, standard axioms only)` (the count includes the five definitions).

`tests/tamper.sh` plants six kinds of fake proof in scratch copies and checks that the gate
rejects each one:

| Test | What it plants |
|---|---|
| sorry | a `sorry` |
| ax2line | an axiom split across two lines |
| evalfake | an `#eval` that prints a fake axiom report |
| macro | a custom macro |
| falsehyp | the classical theorem weakened from `8 ≤ |K|` to `4 ≤ |K|` (false over `𝔽₄`) |
| wrap | a genuine extra axiom with a long name, so the report wraps over several lines |

The Python scripts in `code/` check the mathematics independently with exact arithmetic: the
general-position criterion (`criterion_examples.py`, `check_cb.py`), the finite-field
counterexamples (`counterexamples.py`, `brute9.py`, `classical9*.py`, `count10.py`, `q8conic.py`),
and the Pascal/Pappus hypotheses (`check_stage6.py`–`check_stage8.py`, `examples_stage8.py`).
Saved outputs of the longer searches are in `code/outputs/`. Run the scripts from inside `code/`.
`scratch/PaperAxioms.lean` with its output `scratch/paper_axioms.out` is the axiom run recorded in
the paper (every declaration it names is also checked by `gate.sh`).

## Build

```sh
curl https://raw.githubusercontent.com/leanprover/elan/master/elan-init.sh -sSf | sh   # if Lean is not installed
lake exe cache get
lake build
./gate.sh
bash tests/tamper.sh
```

Toolchain: Lean `v4.33.1`, Mathlib `v4.33.1` (revision pinned in `lake-manifest.json`).

The formal proofs, checking scripts and documentation were developed with the help of a
